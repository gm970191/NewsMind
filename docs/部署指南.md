# NewsMind 部署指南

## 部署方式

### 1. 开发环境部署

#### 环境要求
- Python 3.8+
- Node.js 16+
- LM Studio (本地AI服务)

#### 步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd NewsMind
```

2. **后端设置**
```bash
cd backend
pip install -r requirements.txt
```

3. **启动LM Studio**
- 下载 [LM Studio](https://lmstudio.ai/)
- 启动本地服务 (端口: 1234)
- 加载模型: `qwen2-0.5b-instruct`

4. **启动后端**
```bash
python start_server.py --mode dev
```

5. **前端设置**
```bash
cd frontend
npm install
npm run dev
```

6. **访问应用**
- 前端: http://localhost:3000
- 后端: http://localhost:8000

### 2. Docker 部署

#### 使用 Docker Compose

1. **创建环境文件**
```bash
# .env
DATABASE_URL=sqlite:///./newsmind.db
DEBUG=false
```

2. **启动服务**
```bash
docker-compose up -d
```

3. **查看日志**
```bash
docker-compose logs -f
```

#### 手动构建镜像

1. **构建后端镜像**
```bash
cd backend
docker build -t newsmind-backend .
```

2. **构建前端镜像**
```bash
cd frontend
docker build -t newsmind-frontend .
```

3. **运行容器**
```bash
# 后端
docker run -d -p 8000:8000 --name newsmind-backend newsmind-backend

# 前端
docker run -d -p 3000:80 --name newsmind-frontend newsmind-frontend
```

### 3. 生产环境部署

#### 服务器要求
- Ubuntu 20.04+ / CentOS 8+
- 4GB+ RAM
- 50GB+ 磁盘空间
- 公网IP

#### 系统配置

1. **安装依赖**
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip nodejs npm nginx

# CentOS/RHEL
sudo yum install python3 python3-pip nodejs npm nginx
```

2. **配置防火墙**
```bash
sudo ufw allow 22    # SSH
sudo ufw allow 80    # HTTP
sudo ufw allow 443   # HTTPS
sudo ufw enable
```

#### 应用部署

1. **部署后端**
```bash
cd /opt/newsmind/backend
pip3 install -r requirements.txt

# 创建系统服务
sudo tee /etc/systemd/system/newsmind.service << EOF
[Unit]
Description=NewsMind Backend
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/newsmind/backend
ExecStart=/usr/bin/python3 start_server.py --mode prod
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable newsmind
sudo systemctl start newsmind
```

2. **部署前端**
```bash
cd /opt/newsmind/frontend
npm install
npm run build

# 配置 Nginx
sudo tee /etc/nginx/sites-available/newsmind << EOF
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /opt/newsmind/frontend/dist;
        try_files \$uri \$uri/ /index.html;
    }

    # 后端API代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto \$scheme;
    }
}
EOF

sudo ln -s /etc/nginx/sites-available/newsmind /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

3. **配置SSL (可选)**
```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx

# 获取SSL证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo crontab -e
# 添加: 0 12 * * * /usr/bin/certbot renew --quiet
```

#### LM Studio 部署

1. **下载并安装 LM Studio**
```bash
# 下载最新版本
wget https://github.com/lmstudio-ai/lmstudio/releases/latest/download/LMStudio.AppImage
chmod +x LMStudio.AppImage
./LMStudio.AppImage
```

2. **配置模型**
- 下载 `qwen2-0.5b-instruct` 模型
- 启动本地服务器 (端口: 1234)
- 设置为开机自启

3. **验证连接**
```bash
curl http://127.0.0.1:1234/v1/models
```

## 监控和维护

### 1. 日志管理

```bash
# 查看应用日志
sudo journalctl -u newsmind -f

# 查看 Nginx 日志
sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log
```

### 2. 数据库备份

```bash
# 创建备份脚本
sudo tee /opt/newsmind/backup.sh << EOF
#!/bin/bash
BACKUP_DIR="/opt/backups/newsmind"
DATE=\$(date +%Y%m%d_%H%M%S)
mkdir -p \$BACKUP_DIR
cp /opt/newsmind/backend/newsmind.db \$BACKUP_DIR/newsmind_\$DATE.db
find \$BACKUP_DIR -name "*.db" -mtime +7 -delete
EOF

chmod +x /opt/newsmind/backup.sh

# 添加到定时任务
sudo crontab -e
# 添加: 0 2 * * * /opt/newsmind/backup.sh
```

### 3. 性能监控

```bash
# 安装监控工具
sudo apt install htop iotop

# 监控系统资源
htop
iotop
```

### 4. 更新部署

```bash
# 停止服务
sudo systemctl stop newsmind

# 更新代码
cd /opt/newsmind
git pull

# 更新依赖
cd backend
pip3 install -r requirements.txt

cd ../frontend
npm install
npm run build

# 重启服务
sudo systemctl start newsmind
sudo systemctl reload nginx
```

## 故障排除

### 常见问题

1. **后端启动失败**
```bash
# 检查端口占用
sudo netstat -tlnp | grep :8000

# 检查日志
sudo journalctl -u newsmind -n 50
```

2. **AI翻译失败**
```bash
# 检查 LM Studio 服务
curl http://127.0.0.1:1234/v1/chat/completions

# 检查模型状态
# 在 LM Studio 界面中确认模型已加载
```

3. **前端无法访问**
```bash
# 检查 Nginx 配置
sudo nginx -t

# 检查防火墙
sudo ufw status
```

4. **数据库错误**
```bash
# 检查数据库文件权限
ls -la /opt/newsmind/backend/newsmind.db

# 修复权限
sudo chown www-data:www-data /opt/newsmind/backend/newsmind.db
```

### 性能优化

1. **数据库优化**
```sql
-- 创建索引
CREATE INDEX idx_articles_created_at ON news_articles(created_at);
CREATE INDEX idx_articles_category ON news_articles(category);
CREATE INDEX idx_articles_is_translated ON news_articles(is_translated);
```

2. **Nginx 优化**
```nginx
# 启用 gzip 压缩
gzip on;
gzip_types text/plain text/css application/json application/javascript;

# 设置缓存
location ~* \.(js|css|png|jpg|jpeg|gif|ico)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}
```

3. **系统优化**
```bash
# 调整文件描述符限制
echo "* soft nofile 65536" >> /etc/security/limits.conf
echo "* hard nofile 65536" >> /etc/security/limits.conf
```

## 安全建议

1. **定期更新系统**
```bash
sudo apt update && sudo apt upgrade
```

2. **配置防火墙**
```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing

sudo ufw allow 'Nginx Full'
```

3. **备份重要数据**
- 定期备份数据库
- 备份配置文件
- 备份 SSL 证书

4. **监控安全日志**
```bash

sudo tail -f /var/log/auth.log | grep sshd

```
