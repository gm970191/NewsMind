### 2. 数据模型层 (`backend/app/models/`)

#### `news.py` - 新闻相关模型
```python
class NewsSource(Base):
    """新闻源表"""
    __tablename__ = "news_sources"
    
    id = Column(Integer, primary_key=True, index=True)
    name = Column(String(255), nullable=False, index=True)
    url = Column(String(500), nullable=False, unique=True)
    type = Column(String(50), nullable=False)  # 'web' or 'rss'
    category = Column(String(100), nullable=True)
    weight = Column(Float, default=1.0)
    is_active = Column(Boolean, default=True)
    created_at = Column(DateTime, default=datetime.utcnow)
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)

class NewsArticle(Base):
    """新闻文章表"""
    __tablename__ = "news_articles"
    
    id = Column(Integer, primary_key=True, index=True)
    original_title = Column(String(500), nullable=False)
    original_content = Column(Text, nullable=False)
    original_language = Column(String(10), default='en')
    
    # AI处理字段
    translated_title = Column(String(500), nullable=True)
    translated_content = Column(Text, nullable=True)
    summary_zh = Column(Text, nullable=True)
    detailed_summary_zh = Column(Text, nullable=True)
    
    # 处理状态字段
    is_processed = Column(Boolean, default=False)
    is_title_translated = Column(Boolean, default=False)
    is_content_translated = Column(Boolean, default=False)
    
    # 质量评分
    quality_score = Column(Float, default=0.0)
    translation_quality_score = Column(Float, default=0.0)
    
    # 关联字段
    source_id = Column(Integer, ForeignKey("news_sources.id"))
    source = relationship("NewsSource", back_populates="articles")
```

### 2. 状态管理 (`frontend/src/stores/`)

#### `news.js` - 新闻状态管理
```javascript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import axios from 'axios'

export const useNewsStore = defineStore('news', () => {
  // 状态
  const articles = ref([])
  const loading = ref(false)
  const total = ref(0)
  const currentPage = ref(1)
  const pageSize = ref(20)
  
  // 计算属性
  const hasMore = computed(() => {
    return articles.value.length < total.value
  })
  
  // 动作
  const fetchArticles = async (params = {}) => {
    loading.value = true
    try {
      const response = await axios.get('/api/v1/news/articles', {
        params: {
          skip: (currentPage.value - 1) * pageSize.value,
          limit: pageSize.value,
          ...params
        }
      })
      articles.value = response.data.articles
      total.value = response.data.total
    } catch (error) {
      console.error('获取新闻失败:', error)
    } finally {
      loading.value = false
    }
  }
  
  const loadMore = async () => {
    if (loading.value || !hasMore.value) return
    
    currentPage.value++
    const response = await axios.get('/api/v1/news/articles', {
      params: {
        skip: (currentPage.value - 1) * pageSize.value,
        limit: pageSize.value
      }
    })
    articles.value.push(...response.data.articles)
  }
  
  return {
    articles,
    loading,
    total,
    currentPage,
    pageSize,
    hasMore,
    fetchArticles,
    loadMore
  }
})
```

## 🔄 数据流程

### 1. 新闻采集流程
```
定时任务触发 → 获取活跃新闻源 → 抓取新闻内容 → 去重检查 → 保存到数据库
```

### 2. AI处理流程
```
定时任务触发 → 获取未处理新闻 → 批量AI处理 → 更新处理状态 → 保存结果
```

### 3. 前端展示流程
```
用户访问 → 获取新闻列表 → 渲染组件 → 用户交互 → API调用 → 更新状态
```
